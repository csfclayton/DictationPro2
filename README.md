# 填充練字坊 · DictationPro2

> CSV 題庫自動建組 · 多模式填充練習 · 抽卡圖鑑 · SRS 間隔重複 · 真正語音默書 · iPad 優化

專為中文詞彙／成語練習設計的網頁應用，深色 indigo 玻璃質感介面，針對 iPad 觸控優化。資料完全儲存在瀏覽器本地（localStorage），無需登入、可離線使用。

## 主要功能

### 1. 題庫管理
- CSV 匯入（自動偵測表頭，只需「題目」「答案」）
- 手動新增／編輯（支援拼音、釋義）
- 多選題組測驗、匯出 CSV / 完整 JSON 備份

### 2. 答題模式
- **供詞填充**：10 選 1
- **不供詞填充**：自由輸入
- **語音默書**：Web Speech API 真正 dictation
- 錯題重做、自動儲存進度

### 3. SRS 間隔重複（新增）
- 簡化 SM-2 演算法
- 依答對／答錯自動調整複習間隔
- 主頁顯示「今日待複習」並可一鍵開始複習

### 4. 抽卡圖鑑系統（還原）
- N / R / SR / SSR 稀有度
- 完成測驗獲得抽卡次數（正確率越高越多）
- 卡片圖鑑收集進度
- 抽卡動畫與重複卡累積

### 5. 遊戲化與其他
- XP + 等級稱號（入門學徒 → 一代文豪）
- 本地積分榜（多用戶）
- 完整備份／還原
- 音效開關、語音語言設定

## 使用方法

1. 開啟 [index.html](./index.html)
2. 建立帳戶
3. 題庫管理 → 匯入 CSV 或使用範例成語
4. 選擇模式開始測驗；答完可抽卡
5. 有待複習詞彙時，主頁會出現 SRS 提示

### CSV 格式範例

```csv
題目,答案,拼音,釋義
雖然他們之前吵得很兇，但最後還是_____了。,言歸於好,yan4 gwai1 jyu1 hou2,重新和好
兩人一起克服困難，真正做到_____。,同甘共苦,tung4 gam1 gung6 fu2,一同享福與受苦
```

## 資料安全

- 資料只存在目前瀏覽器 localStorage
- 請定期「備份」匯出 JSON
- 換裝置前先匯出再匯入
