# 填充練字坊 · DictationPro2

> CSV 題庫自動建組 · 多模式填充練習 · 抽卡圖鑑 · 積分榜 · iPad 優化 · 真正語音默書

一個專為中文詞彙／成語練習設計的網頁應用，特別針對 iPad 觸控優化。資料完全儲存在瀏覽器本地（localStorage），無需登入、可離線使用。

## 主要功能

### 1. 題庫管理
- 支援 CSV 匯入（自動偵測表頭，只需「題目」與「答案」兩欄）
- 依檔名自動建立題組
- 手動新增／編輯詞彙（支援拼音、釋義）
- 匯出 CSV 或完整 JSON 備份
- 多選題組進行測驗

### 2. 答題模式
- **供詞填充**：從 10 個選項中選擇正確答案（適合初學）
- **不供詞填充**：按字數自由輸入（較具挑戰）
- **語音默書模式**（新增）：使用 Web Speech API 進行真正的語音輸入與識別
- 隨機出題、可自訂題數
- 錯題重做
- 自動儲存進度

### 3. 遊戲化系統
- XP 經驗值與等級稱號（入門學徒 → 一代文豪）
- 抽卡圖鑑系統（含稀有度）
- 本地積分榜（同一瀏覽器多用戶）
- 答對／答錯／抽卡音效 + 背景音樂

### 4. 其他
- 多帳戶支援（本地）
- 卡片管理（需管理員密碼）
- iPad 觸控優化介面
- 完整資料備份與還原

## 使用方法

1. 開啟 [index.html](index.html)（或部署到任何靜態網站）
2. 建立用戶帳戶
3. 到「題庫管理」匯入 CSV 或手動新增題組
4. 選擇題組與模式後開始測驗

### CSV 格式範例

```csv
題目,答案,拼音,釋義
雖然他們之前吵得很兇，但最後還是_____了。,言歸於好,yan4 gwai1 jyu1 hou2,重新和好
兩人一起克服困難，真正做到_____。,同甘共苦,tung4 gam1 gung6 fu2,一同享福與受苦
```

## 資料安全說明

- 所有資料只存在你目前使用的瀏覽器 localStorage
- 清除瀏覽器資料會導致資料遺失
- 建議定期使用「備份」功能匯出 JSON
- 換裝置或瀏覽器時請先匯出再匯入

## 技術棧

- 純前端（HTML + CSS + JavaScript / React）
- Web Speech API（語音識別與語音合成）
